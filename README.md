# Techcomm Nexus AI

Enterprise AI operations platform for customer service, appointments, case management and internal workflows.

## Status

Foundation stage in progress.

## Core stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL
- Node.js AI Orchestrator
- n8n
- Vercel
- Cloudflare
- Sentry
- Better Stack

## Security principles

- Private repository
- No secrets committed to source control
- Row Level Security in Supabase
- Server-only use of privileged keys
- Environment separation: development, preview and production
- Audit logging for sensitive operations
- Least-privilege access

## Planned portals

- Customer Portal
- Internal Operations Portal
- Administration Portal

## Current stage

Stage 1: repository, database foundation, authentication and roles.
